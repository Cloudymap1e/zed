# Zed Agent

Zed Agent has been removed. Use [External Agents](./external-agents.md) for integrated agent threads such as Codex, Claude, OpenCode, Copilot, Cursor, and Pi Coding Agent. Use [Terminal Threads](./terminal-threads.md) when you want to run an agent CLI or TUI directly in a terminal-backed thread.

For setup help, start with [AI Quick Start](./quick-start.md) or [Agents](./agents.md).
